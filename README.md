# 任务栏歌词 for 网易云音乐（TaskbarLyricsNetease）

在 Windows 任务栏上实时显示网易云音乐正在播放的歌词，效果类似 macOS 顶栏歌词。
歌词以深色底白字的形式显示在任务栏上，鼠标点击可穿透，不影响任务栏任何操作；
点击任务栏也不会把歌词盖住（程序持续保持窗口置顶）。

## 功能特性

- **任务栏歌词**：无边框歌词条，背景色与任务栏一致（可调）、上下内缩贴合任务栏可视区，点击穿透；
- **歌名-歌手前缀**：显示 `歌名 - 歌手 | 歌词`，随歌曲切换自动更新；**歌名中的括号及括号内容自动隐藏**
  （如 `后会无期 (G.E.M.重生版)` 显示为 `后会无期`），可用托盘开关关闭前缀；
- **换歌自动校准**：从网易云本地数据库读取当前歌曲"真实开始播放时刻"锚定进度，
  预加载切歌（检测延迟几十秒）也能自动对齐；反复快速切歌时歌词从头开始；
- **本地优先、抗风控**：歌曲 id 与歌词优先从本地解析（歌曲库 / 播放历史 / 歌词缓存），
  网易云搜索接口被风控时依然正常工作；
- **歌词本地缓存优先**：网易云 `Temp` 目录有歌词缓存时直接用，省网络请求；
- **热键**：`Alt+Shift+←/→` 整体微调进度；`Alt+Shift+↑/↓` 跳上一句/下一句（拖进度条后对齐用）；
- **系统托盘**：右下角音符图标，右键菜单提供**字体大小**（±2px）、
  图形化开关（前缀 / KTV 高亮 / 过滤行 / 暂停变暗 / 空闲提示 / 日志），以及"显示/隐藏歌词"、"退出"；
- **苹方字体**：已安装苹方（PingFang SC / 苹方-简）三个字重，歌词用苹方渲染；
- **单实例**：重复启动自动退出，不会开多个歌词条。

## 使用方法

1. 双击 `build.bat` 编译（只需要 Windows 自带的 .NET Framework，无需装任何东西），
   生成 `TaskbarLyricsNetease.exe`；
2. 双击 `TaskbarLyricsNetease.exe` 运行（无窗口、无控制台）；
3. 打开网易云音乐播放歌曲，歌词就会出现在任务栏上（左下角，位置可调）；
4. **系统托盘**（右下角）会出现蓝色音符图标，右键菜单：
   - **设置（打开 config.ini）**——打开配置文件做高级设置；
   - **字体大小**——"增大 2px / 减小 2px"，实时生效并自动保存（范围 10~40）；
   - **开关项**（点击即切换并自动保存）：显示歌名-歌手前缀 / 逐字高亮（KTV）/
     过滤 作词·作曲 等行 / 暂停时变暗 / 没播放时显示提示 / 写日志；
   - **显示/隐藏歌词**——临时隐藏或恢复歌词条；
   - **退出**——关闭程序。
5. 关闭：托盘右键"退出"，或任务管理器结束 `TaskbarLyricsNetease.exe`。

首次运行会在 exe 同目录自动生成 `config.ini`；托盘开关的改动会自动写回。

## 命令行参数

| 参数 | 作用 |
| --- | --- |
| （无） | 正常运行，隐藏控制台 |
| `--console` | 带控制台运行，实时打印日志 |
| `--probe` | 自检模式：打印 SMTC 会话 / 缓存歌曲 id / 歌词接口 / 配置，然后退出 |

## 热键

| 热键 | 作用 |
| --- | --- |
| `Alt+Shift+←` | 歌词整体提前 500ms |
| `Alt+Shift+→` | 歌词整体延后 500ms |
| `Alt+Shift+↑` | 跳到上一句歌词（并重新校准计时） |
| `Alt+Shift+↓` | 跳到下一句歌词（并重新校准计时） |

（不用 Ctrl 组合是因为中文输入法会拦截 Ctrl+Shift。）

## 配置文件说明（config.ini）

以下为当前运行配置（`config.ini` 中未列出的项使用代码默认值）：

```
FontName=苹方-简            # 字体
FontSize=26                 # 字号（像素），建议 18~26
TextColor=#FFFFFF           # 歌词颜色
ShadowColor=#000000         # 阴影颜色（Layered 模式描边用）
DimColor=#B0B0B0            # KTV 模式未唱部分的颜色
Align=Left                  # Left / Center（仅 Layered 模式）
PaddingX=150                # 歌词条距任务栏左边缘像素（避开开始按钮和图标）
OffsetMs=0                  # 进度偏移毫秒：歌词快填负数，慢填正数
PollMs=500                  # 轮询毫秒（100~5000）
KtvMode=false               # 逐字高亮：true=唱到变白/未唱灰色，false=整句纯白
FilterMetaLines=true        # 过滤 作词/作曲/编曲 等元信息行
DimWhenPaused=true          # 暂停时文字变暗
RenderMode=Solid            # Solid=不透明实心条(最稳，默认) / Layered=分层透明(部分环境不可见)
BackdropColor=#1C1C1C       # 歌词条背景色（默认匹配 Win11 深色任务栏）
BackdropAlpha=90            # Layered 模式半透明黑底透明度 0~255，0 关闭
TrayInsetV=3                # 歌词条上下各内缩像素（贴合任务栏可视区）
TrayMaxWidth=0              # 歌词条最大宽度 px：0=自动(任务栏宽-900)，长歌词也能显示全
ShowIdleText=false          # 没播放时是否显示提示文字
IdleText=等待网易云音乐播放…
ShowSongTitle=true          # 歌词前显示"歌名-歌手"前缀（括号内容自动隐藏），false=只显示歌词
LogToFile=false             # 写 lyrics.log 日志（排查问题时改 true）
```

> 托盘右键菜单中的开关（前缀 / KTV / 过滤行 / 暂停变暗 / 空闲提示 / 日志）点击即切换并自动写回此文件。

## 工作原理（数据来源）

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 歌名/歌手/播放状态 | Windows SMTC 媒体会话（`cloudmusic.exe`） | 实时、无需网络，识别"正在播哪首歌"的主信号 |
| 歌曲 id | 本地优先，按顺序尝试：① 本地歌曲库 `dbTrack`（webdb.dat 内，按歌名匹配，已收录播过的歌）② 播放历史 `historyTracks` 最新记录（含歌名校验，写入延迟自动重试）③ 音频缓存 `Cache\Cache\<歌曲id>-3999-*.uc` 前缀（经歌名校验）④ 网易云搜索接口（仅兜底） | 网易云搜索接口可能被风控（返回加密数据），因此优先用本地来源解析 id |
| 歌词 | ① 本地歌词缓存 `Temp\<MD5(歌曲id)>`（网易云客户端自己缓存的歌词）② 网易云歌词接口 `music.163.com/api/song/lyric?id=...`（按 id 直取，不受搜索风控影响） | 快速切歌也不会漏加载（换歌代数机制，旧加载结果自动作废） |
| 播放起点 | 网易云本地数据库 `Library\webdb.dat`（SQLite 播放历史表） | 用系统自带 winsqlite3.dll 只读查询，取当前歌曲"开始播放时刻"锚定进度；只接受 45 秒内的新鲜记录（避免反复切歌时误用旧起点） |
| 进度 | 估算：真实播放起点 + 计时 + `OffsetMs` | 网易云不上报 SMTC 进度（Pos 恒为 0），这是客户端限制 |

## 歌词进度说明

网易云客户端不向系统上报播放进度（SMTC 的 Pos 恒为 0），因此：

- **连续播放**：换歌时自动从本地数据库校准"真实开始时刻"，歌词自动同步；
- **反复快速切歌**：歌词从开头开始（旧的播放起点会被忽略）；
- **拖动进度条后**（快进/后退）：无法全自动跟随，按 `Alt+Shift+↓`（下一句）或
  `Alt+Shift+↑`（上一句）对齐到正在唱的句子（通常 1~3 下），对齐后自动继续跟随；
- **整体偏移**：个别歌曲歌词本身偏快/偏慢时，按 `Alt+Shift+←/→` 微调，或改 `OffsetMs`。

## 常见问题

- **任务栏上没字**：先跑 `TaskbarLyricsNetease.exe --probe` 看输出。
  - 无 SMTC 会话且缓存目录没 `.uc` 文件 → 网易云没在播放，或歌曲是本地文件/未走缓存；
  - 歌词接口失败 → 检查网络（需要能访问 music.163.com）。
  - **显示歌名而不是歌词** → 歌曲 id 解析失败：通常是刚播的新歌（本地歌曲库/播放历史还没有记录）且搜索接口被风控，换一首歌或过一会儿会自动恢复。
- **字压到图标上**：调 `config.ini` 的 `Align` 和 `PaddingX`。
- **歌词条高出任务栏/色差**：调 `TrayInsetV`（上下内缩）和 `BackdropColor`（背景色）。
- **Win10/11 老版本**：SMTC 走 `TryGetMediaPropertiesAsync`，失败会自动反射回退旧接口 `GetGlobalProperties`。
- **多显示器**：只覆盖主任务栏（Shell_TrayWnd），副屏任务栏暂不支持。

## 已知限制

- 进度为估算（原因见上）：连续播放自动校准；手动拖动进度条后需用 `Alt+Shift+↑/↓` 对齐；
- 只支持网易云音乐（`cloudmusic.exe`）；
- 只覆盖主显示器任务栏；
- 网易云搜索接口可能被风控（已用本地来源规避，但首次播放的全新歌曲可能暂时显示歌名）；
- 编译完全离线：WinRT 元数据已随项目放在 `lib/`，不需要装 SDK。
